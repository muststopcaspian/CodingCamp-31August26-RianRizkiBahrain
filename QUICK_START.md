# 🚀 Quick Start Guide - BRUTALISM EDITION

## Get Started in 3 Minutes!

### Step 1: Open the App (30 seconds)
1. Double-click `index.html` atau drag ke browser
2. App langsung terbuka dengan **BRUTALISM DESIGN** yang bold dan striking!

### Step 2: Initial Setup (1 minute)
1. **Klik icon ⚙️** di kanan atas
2. **Upload foto profil** (optional) - max 2MB
3. **Masukkan nama Anda** (contoh: "John")
4. (Optional) **Ubah Pomodoro time** jika mau (default 25 menit)
5. **Masukkan OpenAI API key** untuk chatbot
6. **Klik "SAVE SETTINGS"**
7. Nama dan foto Anda akan muncul di header!

### Step 3: Add Your First Task (30 seconds)
1. **Ketik task** di kotak input
2. **Pilih priority**: Low, Medium, atau High (color-coded!)
3. **Tekan Enter** atau klik "ADD TASK"
4. Task muncul dengan **BOLD BRUTALIST BORDERS**! ✅

### Step 4: Try the AI Chatbot (1 minute)
1. **Scroll ke AI ASSISTANT section** (left column)
2. **Type pesan**: "evaluate my tasks" atau "give me tips"
3. **Press Enter** atau klik "SEND"
4. AI akan respond dengan insights tentang task list Anda!

## ❓ Common Questions

**Q: Kenapa UI nya jadi "harsh" gitu?**  
A: Itu namanya **BRUTALISM** design! Inspired by brutalist architecture - bold, functional, no-nonsense. Love it or hate it, it's intentional! 😎

**Q: Chatbot ga nyambung/error?**  
A: Check API key di Settings. Kalau error, fallback response akan tetap jalan (rule-based).

**Q: Bisa chat tanpa API key?**  
A: Ya! Fallback responses akan jalan - intelligent pattern matching based on your questions.

**Q: Profile pic hilang setelah reload?**  
A: Check browser tidak dalam private/incognito mode. LocalStorage disabled di mode tersebut.

**Q: Chat history hilang setelah reload?**  
A: Yes, by design. Chat history di memory, tidak persistent. Fresh start setiap reload.

## 🐛 Troubleshooting

### Chatbot Issues
- ✅ Check API key valid (OpenAI format)
- ✅ Check internet connection
- ✅ Try fallback mode (works without API!)

### Profile Pic Issues
- ✅ File must be image (jpg, png, gif, etc.)
- ✅ Max 2MB size
- ✅ Not in private browsing mode

### UI Issues  
- ✅ **Refresh page** if elements look weird
- ✅ **Try dark mode** - might look better!
- ✅ **Zoom browser** if text too small/large
