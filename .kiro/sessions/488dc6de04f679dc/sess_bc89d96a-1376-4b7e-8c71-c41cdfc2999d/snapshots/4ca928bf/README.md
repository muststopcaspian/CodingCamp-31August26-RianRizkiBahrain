# To-Do List Life Dashboard

Web application untuk mengelola tugas harian dengan fitur evaluasi AI menggunakan LLM.

## 🚀 Fitur Utama

- **Greeting Dinamis**: Menampilkan sapaan berdasarkan waktu dan tanggal
- **Focus Timer (Pomodoro)**: Timer 25 menit untuk produktivitas
- **To-Do List**: Kelola tugas dengan fitur lengkap (add, edit, delete, mark done)
- **Quick Links**: Akses cepat ke website favorit
- **Light/Dark Mode**: Tema yang dapat disesuaikan
- **Custom Settings**: Personalisasi nama dan waktu Pomodoro
- **LLM Integration**: Evaluasi otomatis terhadap to-do list Anda

## 🛠️ Teknologi

- **HTML5**: Struktur aplikasi
- **CSS3**: Styling dengan 3D interactive design
- **Vanilla JavaScript**: Logic aplikasi (no frameworks)
- **Local Storage API**: Penyimpanan data client-side

## 🎯 Requirements

- Browser modern (Chrome, Firefox, Edge, Safari)
- Tidak memerlukan backend server
- Tidak memerlukan instalasi dependencies
