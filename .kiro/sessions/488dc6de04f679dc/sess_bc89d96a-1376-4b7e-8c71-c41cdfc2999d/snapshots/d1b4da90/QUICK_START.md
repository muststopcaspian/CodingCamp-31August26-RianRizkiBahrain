# 🚀 Quick Start Guide

## Get Started in 3 Minutes!

### Step 1: Open the App (30 seconds)
1. Double-click `index.html` atau drag ke browser
2. App akan langsung terbuka dan siap digunakan

### Step 2: Initial Setup (1 minute)
1. **Klik icon ⚙️** di kanan atas
2. **Masukkan nama Anda** (contoh: "GibranWapres")
3. (Optional) **Ubah Pomodoro time** jika mau (default 25 menit)
4. **Klik "Save Settings"**
5. Nama Anda akan muncul di greeting!

### Step 3: Add Your First Task (30 seconds)
1. **Ketik task** di kotak "What needs to be done?"
2. **Pilih priority**: Low, Medium, atau High
3. **Tekan Enter** atau klik "Add Task"
4. Task muncul di list! ✅

### Step 4: Try the Pomodoro Timer (1 minute)
1. **Klik "Start"** di Focus Timer section
2. Timer mulai countdown (25:00 → 24:59 → ...)
3. **Klik "Pause"** untuk jeda
4. **Klik "Reset"** untuk reset ke awal

## 🎯 What To Do Next?

### Add More Tasks
- Try adding tasks dengan different priorities
- Mark some tasks sebagai completed (centang checkbox)
- Edit tasks dengan klik "Edit"
- Sort tasks by priority, date, or status

### Create Quick Links
1. **Klik "+ Add"** di Quick Links section
2. **Masukkan nama** (contoh: "Google")
3. **Masukkan URL** (contoh: "https://google.com")
4. **Save** - link ready to use!
5. **Klik "Open"** untuk buka link di tab baru

### Try Different Themes
- **Klik icon 🌙** di header untuk dark mode
- **Klik lagi (☀️)** untuk kembali ke light mode
- Theme akan tersimpan otomatis!

### (Optional) Enable AI Evaluation
Untuk insights dari AI tentang task list Anda:

1. **Dapatkan OpenAI API key**:
   - Daftar di https://platform.openai.com
   - Create API key di dashboard
   - Copy key

2. **Set API key di app**:
   - Buka Settings (⚙️)
   - Paste API key di "LLM API Key"
   - Save

3. **Evaluate tasks**:
   - Tambahkan beberapa tasks dulu
   - Klik "Evaluate My Tasks"
   - Baca AI insights!

**Note**: Tanpa API key, app akan tetap memberikan evaluation (rule-based), jadi tetap useful!

## 💡 Pro Tips

### Task Management
- 🎯 **High priority** untuk urgent & important tasks
- 📅 **Check completed tasks** di akhir hari untuk motivasi
- 🧹 **Clear completed tasks** seminggu sekali
- 📊 **Check statistics** untuk track progress

### Pomodoro Technique
- 🍅 **25 min focus** + 5 min break = 1 pomodoro
- 🎯 **Work on 1 task** selama pomodoro
- ⏰ **4 pomodoros** = take longer break (15-30 min)
- 📵 **Eliminate distractions** during pomodoro

### Productivity Hacks
- ✅ Start with **1-3 high priority tasks** per day
- 🔄 **Review & update** tasks setiap pagi
- 🎉 **Celebrate small wins** - mark tasks done immediately
- 📱 Add your **most-used sites** to Quick Links
- 🌙 Use **dark mode** untuk late night productivity

## ❓ Common Questions

**Q: Kenapa tasks saya hilang setelah clear browser data?**  
A: Data tersimpan di Local Storage. Kalau clear browsing data, Local Storage juga ikut terhapus. Backup tasks penting!

**Q: Bisa pakai tanpa internet?**  
A: Ya! Semua fitur works offline kecuali AI Evaluation (butuh internet untuk call OpenAI API).

**Q: Bisa sync antar device?**  
A: Belum supported. Data hanya tersimpan di browser/device yang sedang dipakai.

**Q: Aman ga nyimpen API key di app?**  
A: API key tersimpan di Local Storage browser Anda, tidak dikirim kemana-mana kecuali ke OpenAI untuk evaluation.

**Q: Gratis?**  
A: App gratis 100%! OpenAI API punya free tier tapi ada limits. Check pricing mereka untuk details.

## 🐛 Troubleshooting

### Timer tidak jalan
- Refresh page
- Check console untuk errors (F12)

### Notifications tidak muncul
- Allow notifications di browser settings
- Klik icon di address bar untuk permissions

### AI Evaluation error
- Check API key valid
- Check internet connection
- Fallback evaluation akan jalan kalau API gagal

### Dark mode tidak tersimpan
- Check browser tidak di private/incognito mode
- Local Storage mungkin disabled
